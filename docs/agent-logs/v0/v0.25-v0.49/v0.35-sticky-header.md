# V0.35 — Sticky header (2026-10-05)
**Agent:** dev-1
**Branch:** story/v0.35-sticky-header · **Status:** done

**What I did**
- The header is `sticky top-0 z-40` on every page and at every width, and keeps its frosted glass look (tint plus 12px backdrop blur, faint bottom border).
- Mobile menu (under lg):
  - It still opens and closes with the button, with Escape (focus goes back to the button), and on navigation.
  - It is now an overlay that hangs below the bar instead of pushing the page down. Its height is capped at `100dvh` minus the header, and it scrolls on its own (`overscroll-contain`).
  - It also closes when focus leaves the header (Tab past the last link) or on a click or tap outside the header.
- Skip link: it lands with `#main` directly below the header, including from a scrolled position.
- Anchors and focus: `html { scroll-padding-top: var(--header-height) }`. Header.tsx measures the header with a ResizeObserver and sets the variable, so it always matches the real height (64px under lg, 60px from lg; 4rem until the first measurement). `Section`'s existing `scroll-mt-4` adds a 16px gap on top. Because the menu is an overlay and closes when focus leaves it, the expanded-menu case never hides a focused element.
- New pages start at the top. Without this, the header could be used from deep in a page and the next page would open part way down, because the router keeps the scroll position. Push/replace navigation scrolls to the top, or to the `#hash` target if there is one. Back/forward is left to the browser.
- Contrast: the header tint went from bg at 70% to **80%**. Now that page content scrolls under the header, a bright photo there at 70% would put muted nav text at 3.58. At 80%, pure white content composites to the same worst-case pixel as the canvas budget, rgb(55 56 63): muted 5.30, accent 5.05, nav pill 5.00. The contrast notes in `index.css` are updated.
- Scroll performance at 375px with 4x CPU throttle is the same as baseline (numbers below).

**How I did it**
- The glass moved from `<header>` to an `aria-hidden` layer (`absolute inset-0 -z-10`) inside it. An element with `backdrop-filter` is a backdrop root (the same reason as the V0.25 note on nested blurs). With the blur on `<header>`, the menu panel that hangs outside the header box could not blur the page behind it. Now the bar layer and the menu panel each blur the real page.
- Overlay vs push-down: with a sticky header, a push-down menu opened deep in a page would shift the whole document by the menu height. The overlay keeps the header height constant, so scroll padding is simply the bar height.
- The menu's `onBlur` only closes the menu when `relatedTarget` is outside the header. A null target (switching windows) leaves it open. Click-outside uses `pointerdown` on the document, and only while the menu is open.
- Height of the header under lg is **64px** (it was 65 before). The 1px border is now inside the glass layer instead of being added to the header box. At lg and up it is 60px (was 61). `src/scenes/blackHole.ts` (V0.36, dev-2) has `HEADER_BAND = 65`. It needs to be 64 to match exactly. That is 1px, so it is harmless, but see Follow-ups.
- Testing gotcha: Playwright's `locator.click()` scrolls sticky elements "into view" by moving the page. To check that opening the menu keeps the scroll position, I used a real pointer click at the button's coordinates. React Router commits navigation in a transition, so the checks wait for `aria-current` before reading the scroll position.
