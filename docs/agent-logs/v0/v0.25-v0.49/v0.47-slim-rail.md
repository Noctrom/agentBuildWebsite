**`--rail-width` (for V0.43 and scenes)**
- Set inline on `<html>` by `Header.tsx`: the rail's real rendered width in px, **rounded up to a whole pixel**, from lg. Below lg it is `0px`. index.css has `--rail-width: 0px` as the value before the script runs.
- It is updated by a ResizeObserver on `<header>` (a layout effect, so it is right before the first paint). It follows route changes, because the current page's button changes width, and breakpoint changes.
- Layout pads the shell with `lg:pl-(--rail-width)`. The area beside the rail is `x = var(--rail-width) .. 100vw`. To center a scene in it, use `(railWidth + viewportWidth) / 2`. Read it with `getComputedStyle(document.documentElement).getPropertyValue('--rail-width')`.
- Measured (Chromium, system sans; the same at 1024 and 1280): `/` 98px, `/about` 98px, `/projects` 112px, `/resume` 113px, `/contact` 111px, `/behind-the-scenes` 187px, 404 98px.

**How I did it**
- `NavButton` (in Header.tsx) renders an `aria-hidden` short label in flow, which sets the collapsed size, and an "expander" (the bubble plus the full label). From lg, for collapsible buttons, the expander is absolutely positioned over the short label, so expanding never changes layout. It is `w-max` and clipped with `max-w-full` (the link's width). On hover or focus, the max-width opens to `--expanded-w` while the full label fades in and the short one fades out. Short forms that are prefixes (Proj, Res, Cont) line up exactly with the start of the full word.
- `--expanded-w` is each full label's measured width, written straight to the expander's style by a ResizeObserver, so there is no re-render. My first version animated to a fixed 14rem cap. That made short expansions finish in about 20ms (the early-frame check caught it), so I switched to the real width.
- No opacity on the expander itself: an ancestor with opacity below 1 is a backdrop root and would drop the bubble's blur mid-fade. Only the label and the bubble fade.
- The focus ring moved from the link to the expander (`group-focus-visible:outline-*`), so it wraps the expanded button rather than the collapsed box.
- The hover grow (1.06) is now `origin-left`, so it never pushes the button toward the screen edge.
- The nav gets `lg:overflow-visible`. The mobile `overflow-y-auto` would otherwise clip the expanded buttons horizontally.
- Removed the `--spacing-rail` token (`w-rail`, `pl-rail`). Nothing else used it.
- The rail width is rounded up: with a fractional padding (97.4px), the first run showed `scrollWidth` 1025 at 1024. That turned out to be a separate, pre-existing V0.42 bug. The closed toast's `sr-only` card sat at the flex end, 1px past the right edge, on every page at every width. I fixed it with `left-0` in its own commit, since AutoPauseNotice is mine. I kept the rounding anyway: it puts the content edge on a whole pixel.
