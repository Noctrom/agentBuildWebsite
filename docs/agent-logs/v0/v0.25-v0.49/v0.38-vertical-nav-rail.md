- Hover: the button grows to 1.06 and a frosted glass bubble (pill, `bg-surface` + 12px backdrop blur + faint border + `glass-edge` rim, the V0.25 recipe) fades and expands in (scale 0.75 to 1, opacity 0 to 1) over 150ms. The old hover background and color change and the hover glow are removed.

- Reduced motion: the grow is only under `motion-safe`. The global reduced-motion rule makes the bubble transition 0s, so it simply appears.
- `--header-height` is now the top bar's height: 64px below lg and 0 from lg. `scroll-padding-top` is also forced to 0 from lg in CSS.

**How I did it**
- There is still one `<header>` with one `<nav aria-label="Primary">`, styled per breakpoint. Below lg it is `sticky top-0`. From lg it is `fixed inset-y-0 left-0 w-rail`. The glass stays on its own `aria-hidden` layer behind the content (V0.35), with the border switching from bottom to right at lg. That keeps the mobile menu panel and the bubbles blurring the real page, since there is no backdrop-root ancestor.
- The bubble is an `aria-hidden` span behind a `relative` label span, driven by `group-hover` / `group-focus-visible` / `group-active`. Tailwind v4's `hover:` is already gated to `(hover: hover)`, so touch gets the press bubble rather than a sticky hover. The backdrop blur is only added while a bubble shows. Six invisible blurred layers would still be re-filtered on every frame of the animated background (the same reason as the S25 note in tone.ts).
- The height for scroll padding is measured on the bar wrapper (`lg:hidden`), not the header. From lg the header is the full viewport height, and the bar is `display:none` there, so the ResizeObserver reports 0.
- New token `--spacing-rail: 12rem` gives `w-rail` / `pl-rail`. The widest button ("Behind the Scenes", 163px at 1.0) fits inside 192px with 16px padding, including its hover scale and focus outline. Measured: every link box is within 0..192.
- Scroll-to-top on navigation in Layout.tsx is unchanged.
