# V0.57 — Button to hide the page content and show only the space background (2026-10-06)
**Agent:** dev-1
**Branch:** story/v0.57-hide-content · **Status:** done

**What I did**
- Footer order: from `sm` one row: © + name, GitHub, LinkedIn, Email, eye button, Animation switch. Below `sm`, stacked: ©, links row, eye button on its own line, switch. DOM order = visual order, so Tab goes Email > eye button > Animation.
- Eye button (`HideContentButton`): open eye + "Hide content" while content shows; crossed-out eye + "Show content" while hidden. The name is set with `aria-label`, and `aria-pressed` is true while hidden. A small glass tooltip shows the same words on hover and on keyboard focus.
- Pressing it hides the skip link, the header (rail from `lg`, top bar and menu below), `<main>`, the auto-pause toast, and the ©, links and switch in the footer. Only the canvas and the button stay.
- The button stays in exactly the same spot. Nothing changes layout (hidden with `visibility` + `opacity`, no `display: none`), and the page can't scroll while hidden. Measured: same bounding box before and after at every width.
- Content comes back with the button again, with Esc, or with a click or tap anywhere else (a full-screen transparent layer under the button). Scroll position is unchanged.
- Nothing is saved: the state belongs to the current history entry, so changing page (including back/forward) or reloading always shows content.
- The background is untouched (no change to `SpaceBackground` or `src/scenes/`), so it keeps animating or stays paused.
- The fade (300 ms opacity + visibility) only runs under `motion-safe`. With the switch off or the OS set to reduce motion it switches instantly (V0.49 rule).
- Hidden parts are `inert`: they can't be clicked or reached with Tab, and screen readers skip them. Only the button stays focusable.
- Focus ring: the global accent outline plus the focus glow. AA scan below.

**How I did it**
- `Layout.tsx` owns the state as `hiddenOn` (the router `location.key` it was hidden on). `contentHidden = hiddenOn === location.key`, so any navigation shows content again with no effect. It passes `contentHidden` to Header, Footer and AutoPauseNotice. Main and the skip link are handled in Layout itself.
- `contentVisibility.ts` has `hideableClass(hidden)`: `invisible opacity-0` plus `motion-safe:transition-[opacity,visibility] duration-300`. Each hidden part also gets the React 19 `inert` prop. I applied it per part instead of on a wrapper, so the header keeps its `sticky` behaviour and the button (inside the footer) stays live.
- Background click: while hidden, Layout renders `fixed inset-0 z-40` with `aria-hidden`, and the button is `relative z-50` above it. Because it is a layer and not a canvas hit test, a click where a link used to be just shows content again. Tested: no navigation happens.
- Scroll lock (`useHiddenContentLock`, a layout effect): cancels wheel events, one-finger `touchmove` and scroll keys (arrows, PageUp/Down, Home, End, and Space unless a button is focused). Any other scroll is put back to the saved position. The layer is `touch-pinch-zoom`, so pinch zoom still works. I chose this over `overflow: hidden` because that drops the scrollbar and shifts the layout and the button. Esc is handled in the same listener.
- Decision: I lock scrolling while hidden. The story says the button stays in exactly the same spot, and a scroll would move it, since it is in the footer flow.
- Decision: the label changes and `aria-pressed` is also set, as the criteria ask, so screen readers announce e.g. "Show content, toggle button, pressed".
- Tooltip: decorative (`aria-hidden`), with a `bg-bg-glass` fill. Below `sm` it sits beside the button (on the right). The first try put it above, where it covered "LinkedIn" in the stacked layout. From `sm` it sits above. Esc dismisses it until pointer or focus leaves (WCAG 1.4.13). No horizontal overflow at 375/768/1280.
- Button is 32×32 px (`size-8`) for a comfortable touch target. Icons are inline SVGs in the Lucide eye / eye-off style, so no new dependency.
