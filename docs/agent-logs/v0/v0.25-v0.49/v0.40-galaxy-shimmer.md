# V0.40 — Contact galaxy core breathes and stars twinkle (2026-10-05)
**Agent:** dev-2
**Branch:** story/v0.40-galaxy-shimmer · **Status:** done

**What I did**
- Core breathing: a soft warm halo (0.32 of the galaxy radius) around the baked core fades in and out on a 6 s cycle, up to 0.35 opacity added on top. At its faintest the core is exactly the V0.39 core, so it never disappears, and the change is slow and smooth, so it never flashes.
- Twinkle: 35% of arm stars, 20% of inter-arm disk stars and every 3rd pink knot (16 in all) each brighten and dim on their own slow wave (stars 1.6–4 s, knots 3–6 s) with random phases, so they never pulse together.
- No intro: both effects are plain functions of scene time, so they run the same from the first frame.
- Reduced motion: with the OS setting or the site's Animation switch off, the canvas does not change at all (the engine draws one still frame).
- Works at 375px and desktop. No stutter: the added frame cost at 4x CPU throttle is within +0.3 ms of leader.

**How I did it**
- Resumed from the paused WIP (336fc16). That draft breathed a 0.16r core sprite, but the centre is already full white in the scene, so the breath hardly showed. I made the halo twice as wide (`CORE_SIZE` 0.32) so it brightens the area around the white centre that still has room to get brighter. I used a warmer colour and set `CORE_PEAK` to 0.35; 0.4 washed out the inner arms in harness frames.
- The draft's twinkle only dimmed stars, so the galaxy looked darker than V0.39. It now swings around 1: `1 + depth * sin(...)`, with depth 0.4–0.7 for stars and 0.4–0.6 for knots, so on average it is as bright as before. A knot's alpha can go above 1, and canvas ignores a `globalAlpha` above 1. So that part goes into a second draw: the draws add up with 'lighter', so two draws give the same light as one.
- Twinkle random numbers come from separate seeds, so the V0.39 star and knot layout is unchanged.
- Measured the brightness with a harness that draws the scene at full brightness: the average light outside the core over 0–30 s (0.1 s steps) at 1280 is old 14 837 190 and new 14 838 496 (+0.01%), so the twinkle adds no net brightening or dimming. The core area averages +2.1%, which is the breath.
