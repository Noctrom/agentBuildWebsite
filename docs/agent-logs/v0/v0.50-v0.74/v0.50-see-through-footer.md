# V0.50 — See-through footer with the Animation switch on the right (2026-10-05)
**Agent:** dev-1
**Branch:** story/v0.50-see-through-footer · **Status:** done

**What I did**
- The footer has no fill and no blur any more (`glassClass.surface` removed): computed background `rgba(0,0,0,0)`, `backdrop-filter: none`, so the space background shows through as it does behind the page.
- No top border line (`glass-edge border-t border-border` removed; computed `border-top-width: 0px`).
- From `sm`: one row, © year + name on the far left, then GitHub, LinkedIn, Email, Animation switch. The switch ends on the content edge (its On/Off box ends at the container's content edge; the button's own 6 px padding sits just outside it).
- Below `sm`: stacked and centred, © line, then GitHub / LinkedIn / Email, then the switch.
- AA over the brightest frame without the glass: scan below; all pass with margin.
- Switch and link behaviour unchanged (same `AnimationToggle`, same link attributes). DOM order = visual order, so Tab goes GitHub > LinkedIn > Email > Animation.
- Checked at 375, 768 and 1280.

**How I did it**
- `Footer.tsx`: `<footer>` without classes. The links `<ul>` and the switch share one wrapper (`flex-col` below `sm`, `flex-row gap-6` from `sm`), so `justify-between` puts © left and the group right. The switch is wrapped in a `div` with `sm:-mr-1.5` to cancel its own `px-1.5`, so its visible end lines up with the content edge.
- Kept the stacked gaps (`gap-4`) and `py-8`, so on phones the © line stays at the same position. That keeps V0.39's `PHONE_BAND_BOTTOM` measurement valid.
- Footer text top at 375×812 on /contact (page is exactly 812 tall, no scroll), measured with Playwright (`scratchpad/v050/measure.mjs`):
  - Before: footer box top 647, © `<p>` line box top 680, glyph text range top 682 → **130 px above the page bottom**.
  - After: footer box top 648 (the 1 px border is gone), © `<p>` top 680, glyph text range top 682 → **130 px above the page bottom, unchanged**. Below the © line the order changed: links row 720–736, switch 756–780 (before: switch 716–740, links 760–776). The footer's total height and bottom are the same.
  - 768×1024 and 1280×800: text top 52 px from the bottom, before and after.
- Contrast: adapted the V0.48 scan (`scratchpad/v050/contrast.mjs`). Footer text, switch track border and knob made transparent; all 7 routes (incl. /contact galaxy and /behind-the-scenes) at 375/768/1280, scrolled to the bottom, 5 frames 800 ms apart, ~1.44 M pixels. Brightest pixel in the text rows rgb(45 43 46) (1280, /resume): fg 11.71, muted 6.36, accent (hover) 6.06. In the switch track box rgb(42 33 35): muted 7.10 (off border/knob, needs 3:1), accent 6.77. The on-state knob (accent-fg on an opaque accent track) is independent of the background. On phones the Contact galaxy sits in the band above the footer and never reaches its text. Numbers added to the contrast notes in `index.css`.
- The auto-pause toast is `sticky` after the footer in the layout and takes its own space, so this change doesn't affect it. The rail still pads the footer via `lg:pl-(--rail-width)`.
