- [x] With the switch Off (including auto-paused from V0.42), UI motion behaves as OS reduced motion does today: hover/focus transitions snap, CSS animations finish at once, and `motion-safe:` effects such as the V0.38 nav-button grow don't happen

- [x] With no saved choice, UI motion follows the OS setting as today
- [x] Changing the switch updates UI motion immediately, without a reload, and in other open tabs too
- [x] No flash of motion on page load when the saved choice is Off (the attribute is set before first paint), and the page still works if storage throws
- [x] Every existing `motion-safe:` / `motion-reduce:` use and the global reduced-motion rule follow the new setting. No component is left on the media query alone; list any exceptions in the log.
