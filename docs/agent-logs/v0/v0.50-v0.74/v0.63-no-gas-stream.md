# V0.63 — Behind the Scenes planet without its gas stream (2026-10-07)
**Agent:** dev-2
**Branch:** story/v0.63-no-gas-stream · **Status:** done

**What I did**
- **No gas stream anywhere in the orbit:** the V0.45 stream is gone on the near side, the far side and while the planet crosses the hole. In a frame-by-frame diff over a full orbit, every frame of leader had stream pixels and none of the branch frames do.
- **Planet unchanged:** same size, bands, lighting, orbit, speed (30 s a turn) and front/behind order. Across the whole orbit, the only pixels that differ from leader are where leader drew the stream (see Verification).
- **Rest of the scene unchanged:** the disk, the three hot spots and their trails, the glow, the lensing and the V0.43/V0.44 motion are untouched. They are covered by the same diff, which shows no other changes.
- **Still frame:** with OS reduced motion or with the footer switch off, the canvas does not change and shows the planet front left of the hole, fully visible and with no stream.
- **Code removed, not hidden:** `PlanetStream`, all `STREAM_*` constants, the `stream` instance and its `update`/`draw` calls are deleted, so nothing runs per frame (−146 lines).
- **Other pages:** only `src/scenes/blackHole.ts` changed, so no other scene is affected.
- **375 and desktop:** checked at 375×812 and 1280×800.

**How I did it**
- Deleted the `PlanetStream` class and its constants. In `draw()`, each planet pass is now one line, `if (planet && planetFar) drawCentered(...)` (and `!planetFar` for the near pass), in the same places as before, so the draw order is unchanged.
- `Planet.radius` was a public field only the stream read, so it is now a local in the constructor. The sprite is built exactly as before.
- Comments updated: the V0.45 note in the file header now says one sprite draw a frame and mentions that V0.63 removed the stream. The `PLANET_START` doc no longer mentions the stream, and the comment before the planet passes in `draw()` was rewritten.
